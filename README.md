# akshattt.com — static replica

A pixel-faithful static mirror of [akshattt.com](https://akshattt.com) (Akshat Singh — Product Designer portfolio), originally built with Framer.

## What's inside

- All 20 pages as static HTML (`index.html` + one directory per route)
- The complete Framer runtime, fonts, images and page code under `framer/` (self-hosted, no external CDN dependency for site assets)
- Original Framer 404 page as `404.html`

`/` `/about` `/work` `/projects` `/contact` `/playgrounddd` `/ui` `/visual-design` `/visual-media` `/photography` `/videography` `/artwork` `/3d-render` `/built-with-ai` `/parkinn` `/ibee` `/ibe` `/cpsignage` `/medikare`

## Deploy

Static site — deploy the repo root to any static host (Vercel, Netlify, GitHub Pages). No build step.
